# پوستهٔ ویندوزی بازسازی‌شده

فایل آماده: [`../release/Nexida-Recovery.exe`](../release/Nexida-Recovery.exe)

این یک برنامهٔ **جدید و مستقل** است، نه سورس یا بازسازی عملکرد برنامهٔ اصلی. یک پنجرهٔ اطلاع‌رسانی، دکمهٔ بستن، آیکون و مشخصات نسخهٔ بازیابی‌شده دارد. آیکون و manifest داخل EXE از منابع اصلی استخراج شده‌اند. هیچ بخشی از `Loader.exe` اصلی را اجرا نمی‌کند و فایل `servers` را نمی‌خواند. متن برنامه به‌صراحت محدودیت آن را نشان می‌دهد.

خروجی برای ویندوز ۶۴ بیتی ساخته شده و به Windows Universal CRT نیاز دارد (معمولاً در ویندوز ۱۰ و ۱۱ موجود است). ساخت و بررسی ساختار PE و تطبیق آیکون و manifest انجام شده، ولی فایل در محیط واقعی ویندوز اجرا یا از نظر نمایش و رفتار تست نشده است.

## ساخت مجدد

Python 3 و Zig نسخهٔ 0.13.0 لازم‌اند. پس از قرار دادن `zig` در PATH، از ریشهٔ مخزن اجرا کنید:

```sh
python windows-shell/build.py
```

در صورت نیاز می‌توان مسیر فایل اجرایی Zig را با متغیر محیطی `ZIG` مشخص کرد. فایل خروجی در `release/Nexida-Recovery.exe` نوشته می‌شود. برای بررسی ایستای فایل پس از نصب `pefile` با pip، دستور `python windows-shell/verify.py` را اجرا کنید.
